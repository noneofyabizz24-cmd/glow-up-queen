# Glow Up Queen — Personal PWA

Gratis persoonlijke prototypeversie.

## Wat zit erin
- Vandaag-dashboard met vullende kroon / Upgrade Score
- Streaks en dagelijkse missies
- 10.000 stappen, slaap, water, homemade food, beweging, posten, Out With It, schermtijd, roken
- Avondreset voor keuken, hal, woonkamer + dinsdag badkamer/toilet
- YouTube-workout embed
- Week vooruitblik / terugblik
- 30-dagen voortgang + energie-log
- Money tracker met inkomsten, uitgaven en saldo
- Life-area dashboard
- Lokale pincode
- Offline PWA-cache

## Belangrijk
Alle data staat lokaal in de browser van het apparaat. Wis je browserdata, dan wis je ook deze gegevens.
Deze eerste gratis PWA-versie koppelt nog niet automatisch met Fitdays, Apple Health of Face ID.

## Starten
Open de map via een lokale webserver, bijvoorbeeld:
python -m http.server 8000

Ga daarna naar http://localhost:8000

Voor installatie op iPhone moet de PWA via HTTPS worden gehost. Gratis hosting kan bijvoorbeeld via GitHub Pages of Cloudflare Pages.
